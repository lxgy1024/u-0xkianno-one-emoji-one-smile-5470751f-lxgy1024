## What it does

`main.ts` (Node 22) writes exactly one emoji — 😊, a warm face with smiling eyes — to `entry.txt`, nothing else. It reads as kind and friendly at a glance, needs no context, and is understood the same way by a stranger of any age or background: a genuine smile, not the plain default smiley and nothing intimate or jokey.

## Run

```sh
node main.ts
```

It writes `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`) and reads the file back to verify it passes the gate: UTF-8 text, 1 to 8 characters, not only white space.
